# SmartFlow ERP

브라우저에서 바로 실행할 수 있는 제조업 생산관리·품질관리 통합 ERP 예제입니다.

## 실행 방법

`index.html`을 브라우저에서 열어 시작합니다. 별도의 패키지 설치나 빌드 과정이 필요하지 않습니다. 데이터를 브라우저 저장소에 기록할 때 브라우저의 로컬 파일 접근 정책이 영향을 주는 경우에는 프로젝트 디렉터리에서 정적 웹 서버를 실행하세요.

## 기능

- 통합 대시보드: 일일 생산량·목표 달성률·검사 합격률·현재고 및 주간 생산 차트
- 품목 관리: 품목코드·품목명·규격·단위·안전재고·기초 재고 CRUD
- 생산계획 및 생산실적: 계획과 실적 연결, 계획별 누적 실적과 달성률 계산
- 품질관리: 품목별 검사 항목·합격 기준·LOT·검사/불량 수량 및 불량 유형 기록
- 재고관리: 기초 재고, 검사 합격 수량, 수동 입고/출고를 반영한 품목별 재고 계산
- 분석: 월별 생산 차트, 품목별 생산량, 불량 유형 및 계획 진행 현황
- JSON 데이터 백업, 생산실적 CSV 다운로드, 반응형 화면, 검색 및 기본 샘플 데이터

## 데이터 저장 및 확장

모든 사용자 입력은 `smartflow-erp-v1` 키를 사용해 브라우저 `localStorage`에 저장합니다. `app.js` 상단의 `LocalStorageAdapter`가 저장과 로딩을 담당하며 UI 및 데이터 모델과 분리되어 있습니다. Cloudflare D1을 연결할 때 이 경계를 API/Repository 기반 저장소로 교체하고, `schemaVersion`을 활용해 스키마 마이그레이션을 추가할 수 있습니다. 현재 버전은 프런트엔드 단독 프로토타입이므로 회원가입, 인증 및 서버 간 데이터 동기화는 포함하지 않습니다.

## 재고 계산 규칙

품목의 현재고는 `기초 재고 + 품질검사 합격 수량 + 수동 입고 − 수동 출고`입니다. 검사 불량 수량이 검사 수량 이상인 품질 데이터의 입고 수량은 0으로 계산되며 재고는 0보다 낮아지지 않습니다. 현재는 검사 결과를 저장하는 즉시 합격 수량을 재고에 반영합니다.
